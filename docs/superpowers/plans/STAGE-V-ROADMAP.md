## How to execute a batch

1. `git pull` (with **Git LFS installed** — `git lfs install` once; `.uasset`, `.png`, `.glb` are LFS).
2. Read the batch's plan top to bottom, then batch 1's *Status* section.
3. Execute task by task with superpowers:executing-plans: failing test first, run it, implement, run it, commit. Every deviation from the plan is a `Ruling:` line (what — why — cost if wrong). Keep a local ledger at `.superpowers/sdd/<plan-name>/progress.md` (gitignored), and **when the batch is done, copy the task table, rulings and deferred minors into a `## Status` section at the end of the plan file** (that's how the next person sees them — batch 1 shows the format).
4. After each batch: `tools/ue_test.sh` (all `Sim.*` green), `tools/ue_smoke.sh` (all `ok`), screenshots of the changed views into `art/review/…`, records (HANDOFF, notes for Tommy, the invented ledger, completion-plan progress), push to `main`, check CI (`gh run list --limit 1`).

| UE tests / smoke | `tools/ue_test.sh`, `tools/ue_smoke.sh` (headless `-nullrhi`) | run the same commands in Git Bash with `UE_ROOT` set, or the editor's Session Frontend → Automation → filter `Sim.` |
| Screenshots | `VK_DRIVER_FILES=/usr/share/vulkan/icd.d/intel_icd.json UnrealEditor … -game -RenderOffscreen -SimShots=<dir> -SimShotViews=aerial,zig,gate,street,harbor` | the same without the prefix |

- The UE `-script=` path must be **absolute** (a relative one resolves against the engine's binaries folder).
- UE's Python log lines land in `unreal/Saved/Logs/SchizoGame.log`, not on stdout — grep there for `ue_import_…: N/N`.
- The first boot after importing new meshes builds them into the DDC: the menu takes longer once. Not a hang.

## Hard-won rules (from batch 1)

- **Linux designer's box: never render on the RX 5700 XT.** The kernel amdgpu driver wedges on UE and hard-crashed the machine on 2026-09-26. Every rendering run gets the iGPU prefix above; headless `-nullrhi` runs are safe. Never `-opengl4`.
- **`-nullrhi` does not compile shaders**: a material bug (e.g. a `ComponentMask` left with default channels) only shows in a rendered run as `Failed to compile Material … Default Material will be used`. After any material script, do one rendered run and grep the log for `Failed to compile`.
- **Set every channel of a `MaterialExpressionComponentMask` explicitly** (r, g, b, a) from Python.
- **UE's glTF import mirrors Y** (right- to left-handed). Author in UE's frame, negate y in Blender (see `building_mesh.py`'s docstring); the import script checks the mirror against the spec.
- **Blender samples images bottom-up and the glTF export flips V**: a UE-side atlas formula needs `+ (0, GRID − 2)` in the Blender preview (see `building_mesh.building_material`).
- **Doorways are sacred**: nothing generated may stand in a door's passage above a 0.45 m step (UE's `MaxStepHeight`); the tests enforce it — keep enforcing it for every new placement.
- **§10 accuracy guard rails** (world-art-plan): no chickens, no camels in the city, no water-wheels, no coins, no common iron, no horses in ordinary city use, no glass windows. The fetched packs are medieval-European in places — use only the explicit allow-lists in the plans.
- **Licences**: every asset gets a row in `art/assets.csv`; `tools/art/license_gate.py` in CI rejects NC/ND/SA/GPL. Quaternius (`LicenseRef-QAL-1.0`) is fine for this private repo, **not** for a public one.
